感情コーチング

難しい場面のためのガイド

まず安全とつながりを守り、落ち着いて境界線を伝え、気持ちがおさまった後に学びとつながり直しを支えます。

大きな気持ち 不安 怒り 切り替え 衝突 つながり直し

感情を支える4つの流れ

何と言えばよいかわからないとき、この順番が手がかりになります。

1

安全を確かめる

体を守り、刺激を減らし、必要なら要求をいったん止めます。

2

つながる

気持ちをやさしく言葉にし、そばにいることを伝えます。

3

導く

わかりやすい境界線と、安全な次の行動を示します。

4

つながり直す

落ち着いたら振り返り、次にできることを練習します。

気持ちがあふれているとき

感情が大きいとき、子どもはすぐに説明したり謝ったりできないことがあります。まず落ち着ける関係を届けます。

  1. 声を少し落とし、みんなが安全か確かめます。
  2. 「今、とても大きな気持ちなんだね」と伝えます。
  3. 「ここに座る？ 少し離れる？」と安心できる選択肢を出します。
  4. 後で、きっかけと次に役立つ方法を一緒に考えます。

言葉かけ：「この気持ちを一人で抱えなくていいよ。一緒に少しずつ進もう。」

不安が大きくなっているとき

不安に対して、約束できない安心を無理に保証するよりも、聞くこと、備えること、小さく試すことが役立ちます。

  1. 何が起きそうで心配なのかを聞きます。
  2. 怖さを認めつつ、怖い結末が決まったようには言いません。
  3. 見学する、質問を練習するなど、小さな一歩を決めます。
  4. 不安が残っていても挑戦した勇気に気づきます。

怒りが安全でなくなりそうなとき

怒りという気持ちは否定せず、叩くことや物を壊すことには静かに境界線を示します。

  1. 危険な物を離し、必要なら安全な距離を取ります。
  2. 「叩かせないよ。安全を守るよ」と短く伝えます。
  3. クッションを握る、足を踏む、そばで座るなどを選べるようにします。
  4. 後で怒りを伝える言葉や行動を練習します。
活動の切り替えが難しいとき

楽しいことを終えて次へ移るのは難しいことがあります。見通しがあると取り組みやすくなります。

  1. 切り替えの少し前に短く予告します。
  2. 次にすることを具体的に伝えます。
  3. 片づけを一つ担当する、絵本を選ぶなどの役割を渡します。
  4. できるだけ同じ流れを繰り返します。
きょうだいや友だちと衝突したとき

すぐに謝罪を求めるより、まず安全と落ち着きを戻し、それぞれの話を聞ける状態を作ります。

  1. 危険な行動を止め、それぞれが落ち着けるようにします。
  2. 急いで決めつけず、双方の話を聞きます。
  3. してはいけない行動と、相手への影響を伝えます。
  4. 物を返す、声をかける、次のルールを決めるなどの修復を支えます。

人間関係のリソースを見る

大人も上手に対応できなかったとき

保護者にも苦しい瞬間があります。誠実なつながり直しは、責任と安心を教える大切な機会になります。

  1. 落ち着いて話せるときに戻ります。
  2. 「大きな声を出した。それはよくなかった」と自分の行動を認めます。
  3. 謝り、境界線は穏やかにもう一度伝えます。
  4. 次に自分が試すことを伝え、子どもの気持ちも聞きます。

言葉かけ：「大好きだよ。もう一度始めよう。私も練習するね。」

短いヒントを探す

言葉かけ、協力、自信、生活リズムのヒントをすぐに確認できます。
