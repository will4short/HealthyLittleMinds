情緒教練

陪伴困難時刻的指南

從安全和連結開始，以平靜方式守住界線，待情緒安定後再教導、回顧與修復。

大情緒 焦慮 憤怒 轉換 衝突 修復 短句

簡單的陪伴步驟

當你一時找不到完美的話語，這四個步驟可以帶你開始。

1

確認安全

保護身體安全、降低刺激，必要時先暫停要求。

2

建立連結

溫和說出感受，讓孩子知道你正在陪伴。

3

清楚引導

說明界線，並提供一個安全的下一步或選擇。

4

重新連結

回到關係中，簡短回顧，練習下一次可用的方法。

依情境選擇

找到最接近當下的情境，從一個小步驟開始陪孩子往前走。

大情緒當情緒比語言更大時先關注安全、安靜陪伴和簡單選擇。 焦慮當孩子被「萬一」困住時給擔心命名，把任務變小，讓下一步看得見。 憤怒當身體想大喊、打人或丟東西時守住界線，同時給憤怒一個安全出口。 轉換當停止或開始變得很困難時使用提前提醒、過渡物和小小的轉換儀式。 衝突當手足或朋友發生爭執時先讓現場慢下來，再進入解決問題。 修復當大家都需要重新開始時不增加羞恥感，重新連結，再練習下一次。

前30秒可以說的話

當你一時想不到怎麼說時，可以直接使用這些短句。孩子情緒很高時，少一點語言往往更有幫助。

情緒很大時「這個感覺真的很大。我在這裡。我們先讓每個人都安全。」
擔心占據腦袋時「你的擔心想保護你。我們先找一個現在能做的小步驟。」
憤怒變得不安全時「你可以生氣，但我不會讓你打人。你可以跺腳、捏緊東西，或先退一步。」
轉換很難時「再過一分鐘我們就要換到下一件事。你想拿著這個走，還是牽我的手？」
發生衝突時「先暫停。我會聽每個人說。先讓身體安全，再一起解決。」
需要修復時「剛才對我們都很難。我愛你。我們可以把那個時刻重新練一次。」
當情緒大到無法承受時

情緒壓倒孩子時，他可能還無法解釋、解決問題或立刻道歉。先提供穩定的陪伴。

  1. 降低音量，先確認每個人的安全。
  2. 描述你看到的狀況：「現在這個感覺好像很大。」
  3. 提供陪伴或空間：「我可以坐在這裡，或給你一些空間。」
  4. 之後再一起找出觸發原因，以及下一次可用的一個方法。

可用話語：「你不用一個人承受這個感覺。我們一步一步來。」

當擔心愈來愈大時

焦慮常常想得到大人無法保證的答案。把重點放在聆聽、準備和可做到的小步驟。

  1. 問問孩子，擔心正在告訴他可能會發生什麼事。
  2. 承認感受，但不把擔心的結果說成必然會發生。
  3. 一起安排一個小步驟，例如先參觀新地方或練習提出問題。
  4. 孩子完成一步後，看見他的勇氣，即使擔心仍然存在。

當憤怒變得不安全時

生氣是可以被接納的情緒，但傷害人或破壞物品不是可以接受的行為。家長需要守住安全而不羞辱孩子。

  1. 移開危險物品，並保持適當距離。
  2. 清楚說出界線：「我不會讓你打人。」
  3. 提供安全替代方式，例如用力踩地、抱緊枕頭或坐在附近。
  4. 之後練習下次生氣時可以說的話或做的動作。
當改變活動很困難時

停止喜歡的活動、開始必要的事情，對孩子並不容易。可預測的安排能減少拉扯。

  1. 在轉換之前給孩子簡短提醒。
  2. 用具體句子說明接下來會發生什麼。
  3. 提供一個收尾任務，例如收一件玩具或選睡前故事。
  4. 盡可能重複相同而簡短的日常步驟。

當手足或朋友發生衝突時

不要急著要求立即道歉。慢下來，讓每個孩子能被聽見，也讓安全重新回到現場。

  1. 停止不安全行為，先協助孩子各自安定。
  2. 聽聽每個人的說法，不要太快判定責任。
  3. 說明界線以及這個行為造成的影響。
  4. 支持修復，例如歸還物品、關心對方或提出公平安排。

當家長沒有處理好時

家長也會有艱難時刻。真誠的修復能教孩子負責任，並重新建立連結。

  1. 等自己能平靜說話時，再回到孩子身邊。
  2. 不找藉口地說出自己的行為：「我剛才大吼，這是不對的。」
  3. 道歉，並以尊重的方式重新說明界線。
  4. 告訴孩子你下次會嘗試什麼，也聽聽他的感受。

可用話語：「我愛你。我們可以重新開始，我也會繼續練習。」
